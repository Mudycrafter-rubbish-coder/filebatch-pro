Privacy policy

Your files stay yours.

File processing

FileBatch Pro processes selected files on the user's computer. The desktop application does not upload file contents, filenames, directory names, analytics, or usage telemetry.

License verification

When a paid license is activated or needs validation, the app sends the public product identifier and the user's license key to the payment provider's license API. It does not send selected files or payment card data. A short offline grace period is supported after successful validation.

Payments

Payments, card entry, tax calculation, invoices, refunds, and subscription management occur on the payment provider's hosted service. The desktop application never collects payment card details.

Local data

The application may save an encrypted license key and undo records under the current Windows user's local application-data folder. Undo records are local and can be removed by the user.

This website

This static website does not include analytics or advertising trackers. Downloads are hosted by GitHub and payment links will be hosted by the payment provider.
