# FileBatch Pro 2.0

The first public trial release includes 70 tools across seven groups:

- 17 text tools
- 15 CSV and JSON tools
- 7 Excel tools
- 8 PDF tools
- 11 image tools
- 12 file and ZIP tools

Every operation uses a preview table and produces local output without cloud
uploads. Existing destinations are collision-protected, and the latest
successful run can be undone.

The trial includes every tool, unlimited previews, and up to ten source files
per run. Pro removes the per-run file limit.

## Compatibility

Windows 10 and Windows 11, 64-bit. The binary is not code-signed in version
2.0, so Windows may display an unknown-publisher warning. Compare the SHA-256
checksum before running. Pro checkout is intentionally disabled until hosted
payment, license activation, refund handling, and a real test purchase have
been verified.
