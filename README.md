# FileBatch Pro

Official public download and product information for FileBatch Pro 2.0.

FileBatch Pro is a private Windows EXE with 70 batch tools for text, JSON, CSV,
Excel, PDF, images, ZIP archives, and file organization.

The free trial is published under Releases. The trial includes every tool,
unlimited previews, and up to ten source files per run.

Official site: https://mudycrafter-rubbish-coder.github.io/filebatch-pro/
