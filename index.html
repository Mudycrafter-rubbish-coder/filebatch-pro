Before downloading

Small print,
plain language.

Does the trial expire?

The trial has no time limit. It allows unlimited previews and up to ten source files per run.

Why does Windows show an unknown publisher?

Version 2.0 is not code-signed yet. The release page publishes the SHA-256 checksum so the downloaded EXE can be verified.

Does it overwrite existing files?

No. Output paths are collision-checked, and the application chooses a numbered name when necessary.

Is the source code included?

The public download is the compiled trial application. It is commercial software, not an open-source release.

What does payment verification collect?

The app asks only for the license key from the payment receipt. Card details are entered on the provider's hosted checkout, never in the EXE.
